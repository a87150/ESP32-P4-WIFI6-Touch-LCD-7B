# system_monitor — ESP-Brookesia 0.8 desktop system for the 7B board

ESP-Brookesia **0.8** launcher system for `ESP32-P4-WIFI6-Touch-LCD-7B`
(1024 × 600 MIPI-DSI, GT911 touch, ESP32-C6 Wi-Fi 6 / BLE over ESP-Hosted SDIO).

Full description (features, partition layout, media formats, known limitations):
[`docs/BROOKESIA_7B_ZH.md`](../../../../docs/BROOKESIA_7B_ZH.md) ·
[`docs/BROOKESIA_7B.md`](../../../../docs/BROOKESIA_7B.md)

## Apps

| Package id | Source | Notes |
| --- | --- | --- |
| `brookesia.system.super.shell` | vendored `system/brookesia_system_super` | Desktop, status bar, recents (CLEAR ALL), wallpaper, gestures |
| `brookesia.general.settings` | vendored `app/brookesia_app_settings` | Wi-Fi (IP/MAC, auto-reconnect), Bluetooth (BLE scan), display, sound, time zone, language |
| `brookesia.waveshare.system_monitor` | `components/brookesia_app_system_monitor` | Disk aggregate + 90 % alarm, CPU/GPU temperature in the ring centres, DISK I/O, `TEMP_ALARM_C = 90.0` → `HIGH!` |
| `brookesia.waveshare.music` | `components/brookesia_app_music` | Opens on the player (no autoplay); a 320 dp drawer lists 5 tracks per page, WAV only, background playback, 300 dp cover, seek + volume + sample rate / bit depth / bitrate / size |
| `brookesia.waveshare.gallery` | `components/brookesia_app_gallery` | Opens on the first picture (no autoplay); a 320 dp drawer lists 5 rows per page (name, resolution, size); slideshow (4 s), format / depth, set wallpaper |
| `brookesia.waveshare.video` | `components/brookesia_app_video` | Opens on the player (no autoplay); a 320 dp drawer lists 5 movies per page; MJPEG (concatenated JPEG), hardware decode, 12 fps, no audio, double-tap pause |

## Board support

The 7B board package lives in the vendored HAL tree:
`hal/brookesia_hal_boards/boards/waveshare/esp32_p4_wifi6_touch_lcd_7b/`
(copy of the Espressif P4X function-EV board with backlight on GPIO 32, camera
removed, 32 MB flash + custom partition table, 200 MHz HEX PSRAM, ESP-Hosted
SDIO C6: RST 54, CLK 18, CMD 19, D0-D3 14-17, 40 MHz 4-bit).

## Build (ESP-IDF 6.1 — required by Brookesia 0.8, `lib_utils` pins `>=6.0,<=6.2`)

```powershell
# from the ESP-IDF environment
cd firmware/brookesia_master/examples/system_monitor
idf.py set-target esp32p4                       # first time only
idf.py gen-bmgr-config -b esp32_p4_wifi6_touch_lcd_7b   # first time only
idf.py build
```

Run `idf.py reconfigure` after adding a component under `components/`,
otherwise IDF does not pick it up.

## Flash

Only the `factory` app and the `storage` (littlefs) data partition are written;
bootloader, partition table, NVS and the factory assets are never touched.

```powershell
.\flash_app.ps1 -Port COMx
# equals: write-flash 0x110000 build\system_monitor.bin 0x1000000 build\storage.bin
```

| Partition | Offset | Size |
| --- | --- | --- |
| `factory` (app) | `0x110000` | 14.94 MB |
| `storage` (littlefs) | `0x1000000` | 16 MB |

The partition table at `0x8000` only needs flashing when `partitions.csv`
changes (backups in `firmware/backups/`). Factory restore: flash
`firmware/ESP32-P4-WIFI6-Touch-LCD-7B-FactoryOnly.bin` at `0x0`.

## Assets

Everything under `littlefs/` is packed into `build/storage.bin`, so reflash
`storage` after changing it.

| Path | Content |
| --- | --- |
| `apps/<package id>/res/` | Runtime app packages, generated at build time |
| `system/super/shell/` | Shell UI package, wallpaper path in `system/super/wallpaper.txt` |
| `system/fonts/` | `NotoSansSC-Regular.subset.ttf` (Chinese subset), `Telex-Regular.ttf` |
| `pictures/` | Sample pictures for the Gallery app |
| `sounds/` | Sample WAV files for the Music app |
| `videos/` | Sample MJPEG movies (`976 × 432`, generated by `tools/make_demo_videos.py`) |

Media can also be read from an SD card (`/sdcard`, `/sdcard/pictures`,
`/sdcard/music`, `/sdcard/videos`). Video files must be plain concatenated
JPEGs; `tools/make_mjpeg.py` converts a GIF or an image sequence:

```bash
python tools/make_mjpeg.py frames/ movie.mjpeg --size 976x432 --quality 70
```

## PC stats for the System Monitor app

`scripts/pc_agent.py` (repository root) broadcasts one JSON datagram per second
to UDP port 9999 with CPU / memory / disk / GPU / network data. GPU values need
an NVIDIA card (`nvidia-smi`).

## Notes

- No SD card inserted → `sdmmc_init_ocr ... 0x107` noise at boot, expected.
- No classic Bluetooth / A2DP (the C6 firmware ships BLE only).
- Video is a fixed 12 fps with no audio track; author at `976 × 432` for
  full-screen playback at native scale.
- Gallery, music and video open on their main view; a 320 dp drawer (five rows
  per page) slides over the right side and nothing is loaded or played until a
  row is tapped, and "refresh" only rescans.
- Waveshare publishes a XiaoZhi AI image for this board (✅ in the wiki table),
  but it replaces this firmware and partition table; the two cannot be switched
  in one click. Restore with `firmware/ESP32-P4-WIFI6-Touch-LCD-7B-FactoryOnly.bin`.
